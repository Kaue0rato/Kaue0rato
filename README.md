## 🚀 Projetos em destaque

### [Empório da Música — Assistente de Atendimento com IA](https://github.com/Kaue0rato/emporio-da-musica-ai-assistant)
Agente em Python para atendimento, com ferramentas de consulta a catálogo e pedidos, recuperação de políticas usando **BM25**, integração opcional com a **OpenAI Responses API** por *function calling*, modo local determinístico e testes automatizados.

`Python` `OpenAI API` `RAG / BM25` `Function Calling` `Pytest`

### [The Alter Ego — Interface de Chat](https://github.com/Kaue0rato/parte-visual_-teste)
Protótipo de interface de conversa desenvolvido com componentes reutilizáveis, gerenciamento de estado e layout responsivo. As respostas são simuladas no front-end para validar a experiência de interação.

`Next.js` `React` `TypeScript` `Tailwind CSS` `Radix UI`

### [Portal de Notícias com IA](https://github.com/Kaue0rato/Piloto-Site-noticia)
Protótipo em Django que explora geração automática de resumos e classificação *zero-shot* de textos para sinalizar possíveis notícias falsas, utilizando modelos da biblioteca Transformers.

`Python` `Django` `Transformers` `NLP`
